behavioral states. When cursor is idle, nearby stars cluster toward the mouse
and form a temporary constellation. On click, stars snap into a `JH` initials

## Key Architecture Decisions

### Architecture Fixes (added to scope during review)
1. **visibilitychange handler** — reset `prevTimestamp = null` on tab return.
   Without this, dt spike on tab return causes physics explosion.
2. **getContext null guard** — `if (!ctx) { fallback; return; }`
3. **fillStyle batching by layer** — 3 state changes per frame, not 1600.
4. **First-frame skip** — `if (!prevTimestamp) { prevTimestamp = t; return; }`
5. ~~**Click-during-reinit guard**~~ — removed. Single-threaded JS, no race condition possible.

## Complete Implementation Spec

```
index.html
  - <canvas id="starfield" aria-hidden="true">
  - Load scripts: config.js, starfield.js, input.js, main.js

styles/main.css
  - body { margin:0; overflow:hidden; background:#0a0a0f; }
  - canvas { position:fixed; top:0; left:0; width:100%; height:100%; }
  - @media (prefers-reduced-motion: reduce) { canvas { display:none; } }
    CSS only. Do NOT also add JS checks or "static render" — that contradicts CSS.

scripts/config.js
  LAYER_COUNT=3, STAR_COUNT=[300,500,800], Z_NEAR=1, Z_FAR=1000
  FOCAL_LENGTH=300, INFLUENCE_RADIUS=120, BASE_REPULSE=2
  MAX_CURSOR_VEL=40, SUPERNOVA_IMPULSE=8, MAX_STAR_VEL=15
  SLOW_FRAME_THRESHOLD_MS=25  -- 1.5× at 60Hz; replaces display_Hz calculation
  FALLBACK_STAR_COUNT=[150,250,400]  -- used when perf fallback triggers
  -- Float32Array field indices (FIELDS=12: 8 active + 4 reserved for Phase 2)
  FIELDS=12
  FIELD_X=0, FIELD_Y=1, FIELD_Z=2
  FIELD_VX=3, FIELD_VY=4
  FIELD_ALPHA=5, FIELD_LAYER=6, FIELD_PHASE=7
  -- Phase 2 JH sigil (reserved, initialized to 0, unused in Phase 1):
  FIELD_TARGET_X=8, FIELD_TARGET_Y=9, FIELD_MODE=10, FIELD_TIMER=11

scripts/starfield.js
  - Float32Array pool: 12 fields per star (8 active + 4 reserved for Phase 2)
    1600 stars × 12 fields × 4 bytes = ~77KB total
  - project(x, y, z): helper for force field + supernova (not render hot path)
      returns { sx: (x/z)*FL + halfW, sy: (y/z)*FL + halfH }
  - init(): random x/y/z, seeded layer velocities, random phase offset,
    reserved fields initialized to 0
  - update(mouse, dt):
    - cursor force field: project each star, if dist(sx-mx, sy-my) < INFLUENCE_RADIUS:
        repulse = (mouse.vel / MAX_CURSOR_VEL) * BASE_REPULSE
        direction = normalize(starScreenPos - mousePos)
        apply repulse * direction to vx/vy
      (uses project() — reuse projected coords for edge recycle check below)
    - supernova impulse if mouse.clicked: radial outward from (clickX, clickY),
        direction = normalize(starScreenPos - clickPos),
        magnitude = SUPERNOVA_IMPULSE / max(distance, 1)
        apply magnitude * direction to vx/vy
        velocity cap: vx = clamp(vx, -MAX_STAR_VEL, MAX_STAR_VEL) (same for vy)
      applied to all layers simultaneously
    - edge recycling: if sx < 0 || sx > w || sy < 0 || sy > h (uses projected
      coords already computed above — no duplicate projection):
        re-enter at opposite edge, reset z = Z_FAR, reset vx/vy to layer base speed
      NOTE: z is static (no vz component) — floating-in-space aesthetic, not warp.
      z < Z_NEAR condition removed (dead code with static z).
    - alpha = 0.7 + 0.3*sin(elapsedMs * 0.002 + phase)  -- twinkle_freq = 0.002 rad/ms
  - render(ctx):
    - ctx.clearRect(0,0,w,h)
    - per layer: set fillStyle once; loop stars:
        inline projection (no allocation): sx = (x/z)*FL + halfW; sy = (y/z)*FL + halfH
        z safety: skip if z <= 0 (guard against NaN propagation)
        set ctx.globalAlpha = pool[i*FIELDS + FIELD_ALPHA]  -- per-star twinkling
        r = clamp((BASE_RADIUS/z)*FOCAL_LENGTH, 0.3, 3)
        layer 1: ctx.arc(sx, sy, r, 0, Math.PI*2); ctx.fill()
        layers 2+3: ctx.fillRect(sx - r, sy - r, r*2, r*2)  -- centered, ~3x faster
        skip if sx/sy out of canvas bounds (clip check)
      after each layer: ctx.globalAlpha = 1  -- reset

scripts/input.js
  - mousemove listener: update x,y, compute vel=sqrt(dx²+dy²)
  - velocity EMA: smoothedVel = smoothedVel*(1-alpha) + currentVel*alpha
    where alpha = 1 - exp(-dt / TAU_MS), TAU_MS=80. Frame-rate independent.
    (Ring buffer abandoned: event-rate dependent, browser-variant, wrong.)
  - click listener: set clicked=true, clickX=x, clickY=y (CSS pixel space)
  - getMouseState(): DESTRUCTIVE READ — resets clicked=false after returning state.
      const state = { x, y, vel: smoothedVel, clicked, clickX, clickY };
      clicked = false;  // consume the click — prevents per-frame re-application
      return state;
  - NOTE: all coordinates in CSS pixel space. DPR scaling is render-only.

scripts/main.js
  - prefers-reduced-motion: TWO-LAYER guard:
      CSS: @media (prefers-reduced-motion: reduce) { canvas { display:none; } }
      JS:  if (matchMedia('(prefers-reduced-motion: reduce)').matches) return;
           (prevents RAF CPU burn even when canvas is hidden)
      NOTE: JS check returns early only — NO static render. CSS handles the visual.
  - COORDINATE CONTRACT: All game logic (projection, force field, impulse, clipping)
    runs in CSS pixel space. DPR transform applied once via setTransform at render time.
    Mouse events deliver CSS pixel coords natively — no scaling needed in input.js.
  - init(): canvas DPR setup:
      canvas.width = Math.round(window.innerWidth * devicePixelRatio)
      canvas.height = Math.round(window.innerHeight * devicePixelRatio)
      canvas.style.width = window.innerWidth + 'px'
      canvas.style.height = window.innerHeight + 'px'
      ctx.setTransform(devicePixelRatio, 0, 0, devicePixelRatio, 0, 0)
      -- use setTransform not scale: scale() stacks on repeated resize calls
    then: starfield init, input bind
  - Perf fallback: activeCount = [...STAR_COUNT]  -- mutable loop cap, not pool reinit
  - RAF loop:
    if (!prevTimestamp) { prevTimestamp = t; requestAnimationFrame(loop); return; }
    dt = min(t - prevTimestamp, 33)  -- cap at 33ms (2 frames) to prevent physics spiral
    prevTimestamp = t
    if (dt > SLOW_FRAME_THRESHOLD_MS) slowFrameCount++ else { slowFrameCount=0; cleanFrameCount++ }
    if (slowFrameCount >= 3) {
      activeCount = activeCount.map(n => Math.floor(n/2));
      console.warn('Perf fallback: halved star counts');
      slowFrameCount = 0; cleanFrameCount = 0; isReduced = true;
    }
    if (cleanFrameCount >= 60 && isReduced) {
      activeCount = [...STAR_COUNT];  -- restore via loop cap, no reinit, no pop-in
      isReduced = false;
    }
    update(mouse, activeCount, dt) + render(ctx, activeCount)
  - visibilitychange: document.addEventListener('visibilitychange', () => {
      if (!document.hidden) prevTimestamp = null; })
  - resize (debounced 100ms): reinit canvas size + DPR + pool
```
